# Протокол

Локальный MVP автоматического протоколирования встреч на FastAPI и Vue 3. Загрузите аудио или видео, прослушайте нужное место по метке, уточните имена участников, отредактируйте протокол и отправьте выбранные поручения в YouGile.

## Запуск на Windows

Из корня проекта в PowerShell. Нужны Python 3.11 или 3.12 (64-разрядный) и Node.js 22.12+.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-ml.txt
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --env-file .env
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Для первого знакомства нажмите **Открыть пример**. В примере есть синтетическая запись, подготовленная стенограмма и протокол. Для демонстрации достаточно установить зависимости из `requirements.txt`.

При первой обработке своей записи сервис скачает открытые веса Whisper и диаризации, всего около 0,5 ГБ. Чтобы скачать заранее, выполните `.\.venv\Scripts\python.exe -m backend.setup_models` из корня. Прогрев читает переменные окружения процесса, поэтому для нестандартных `WHISPER_MODEL` и `MEETING_MODEL_DIR` задайте их также в PowerShell перед прогревом. После загрузки моделей можно задать `HF_HUB_OFFLINE=1` в `.env`. На CPU время обработки зависит от длительности записи.

## Как работает обработка

- **Аудио и видео.** Извлечение звуковой дорожки в моно 16 кГц через PyAV. Поддерживаются MP3, WAV, M4A, FLAC, AAC, OGG, OPUS, MP4, WEBM, MOV и MKV. При воспроизведении оригинала набор кодеков зависит от браузера.
- **Говорящие.** Sherpa-ONNX выделяет голосовые интервалы и группирует их по участникам. Если известно число участников, его можно указать при загрузке. Метки сопоставляются со словами Whisper по времени. Имена задаются вручную в карточке встречи.
- **Протокол.** По русскоязычной стенограмме локальные правила составляют черновик сводки, тем, решений и поручений. Формулировки и сроки можно исправить до отправки. Неявные поручения и относительные сроки требуют проверки человеком.
- **Хранение.** Оригиналы, SQLite и история отправок сохраняются в `data/`. Стандартный лимит файла 250 МиБ. Процесс Uvicorn запускается с одним воркером. Данные приложения и обработка остаются на машине, а при отправке в трекер передаются выбранные поручения. Доступ рассчитан на локальный запуск на `127.0.0.1`.
- **Выгрузка.** Markdown содержит протокол и стенограмму, CSV содержит поручения, JSON сохраняет структурированный результат.

## Подключение YouGile

Получите API-ключ и идентификатор нужной колонки по [документации YouGile REST API](https://ru.yougile.com/api-v2). Заполните `YOUGILE_API_KEY` и `YOUGILE_COLUMN_ID` в `.env`, перезапустите сервис. `YOUGILE_ASSIGNEES` позволяет сопоставить имя из протокола с ID пользователя. Если пары нет, имя указывается в описании карточки. Дата переносится в стикер дедлайна.

Проверьте и сохраните протокол, отметьте нужные строки в **Поручениях** и нажмите **В трекер**. YouGile получает стабильный ключ идемпотентности для каждого поручения, сервис сохраняет ID созданной карточки в истории. Для другой системы можно задать `TASK_WEBHOOK_URL` и при необходимости `TASK_WEBHOOK_TOKEN`. Вебхук принимает JSON с полями `event`, `idempotency_key`, `meeting`, `task` и отвечает JSON с `external_id` и необязательным `url`. Обработчик может дедуплицировать запросы по заголовку `Idempotency-Key`.

## Разработка

Для работы с Vue запустите `npm.cmd --prefix frontend run dev` параллельно с FastAPI на порту 8000. Vite проксирует `/api` на бэкенд. При запуске из собранного интерфейса FastAPI отдаёт и API, и статику. Схема API доступна на [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

В Git Flow `main` хранит релизы, `develop` объединяет проверенные изменения. Новые функции разрабатываются в `feature/*` от `develop` и вливаются обратно после проверки. Релиз готовится в `release/*` и вливается в `main` и `develop`.
